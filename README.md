# Meditation Timer

Welcome to the **Meditation Timer** project! This is a simple yet effective tool designed to help users practice mindfulness and relaxation by offering timed meditation sessions accompanied by soothing nature sounds.

## Features

- **Choose Your Session Length**: Select between a 5-minute or 10-minute meditation session.
- **Relaxing Nature Sounds**: Enjoy calming nature music to enhance your meditation experience.
- **User-Friendly Interface**: Easy-to-use buttons and a clean design make it simple to start your meditation journey.

## Technologies Used

1. HTML: For structuring the web page.
2. CSS: For styling the interface and buttons.
3. JavaScript: For handling the timer functionality.
